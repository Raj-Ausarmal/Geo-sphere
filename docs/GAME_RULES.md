# Game rules

Each expedition contains up to ten different countries drawn from the selected difficulty and region. A correct response awards 100 points plus a 25-point bonus for each active streak. A wrong answer, or letting the 45-second question timer expire, ends the streak. Accuracy is correct answers divided by attempted answers.

For Country Locator, drag to rotate, scroll to zoom, and click the outlined country. For Capital and Flag challenges, choose one of four answers. After feedback, the next question begins automatically.
